# 智能音乐工坊 PRO

一个在浏览器里用的音乐制作工具。打开网页就能编曲、试听、导出，不需要安装任何软件。

在线使用：https://yh14466.github.io/music-studio-pro/

首次部署需要等 1-2 分钟。

## 功能

**编曲**

- 多轨时间线，可以写旋律、贝斯、和弦、琶音和鼓组
- 在网格上点击或拖拽画音符，支持框选、复制、量化和连音细分

**AI 辅助生成**

- 内置 10 种风格（Lo-Fi、流行、EDM、Synthwave、摇滚、爵士、电影配乐、环境等）
- 选定风格和情绪参数后，一键生成完整的编曲草稿，再手动修改
- 支持单轨重写、风格迁移、动机续写

**音色**

- 6 种合成器音色（主音、拨弦、Pad、贝斯、铃音、风琴）
- 8 件鼓组（底鼓、军鼓、拍手、闭镲、开镲、通鼓、边击、吊镲）
- 全部用 Web Audio 实时合成，没有加载任何采样文件

**混音**

- 每轨独立控制音量、声像、混响和延迟发送
- 主输出带 3 段 EQ 和砖墙限制器

**导入导出**

- 导出 WAV 音频、MIDI 文件、工程 JSON
- 支持分享链接，别人打开链接就能还原你的工程

**其他**

- 6 套配色主题
- 屏幕钢琴键盘，支持电脑键盘弹奏（A-L 白键，W/E/T/Y/U 黑键）
- 本地作品库，保存编过的曲子

## 关于 AI 作曲

这里的“AI”指的是一套基于音乐理论的规则化生成算法，不是神经网络或大语言模型。

生成过程大致是这样的：

- **和弦**：从风格预设的和弦走向里选，用声部进行代价函数挑选转位，避免声部大跳
- **旋律**：按 2 小节一个乐句生成，带有动机重复、模进、拱形力度、经过音和前倚音
- **节奏**：每个风格有独立的鼓组模板、贝斯律动和琶音模式
- **曲式**：按总小节数自动划分“引子—发展—高潮—尾声”，不同段落的密度和力度不同
- **种子**：所有随机性由种子驱动，同一种子生成相同结果，可以复现

这么设计的原因是：纯前端运行，没有服务器；生成逻辑都在代码里，可以查阅；点一下立刻出结果，不用等网络请求；生成的是草稿，你可以随意修改，AI 只是帮你起步。

如果你的期待是“输入一句话，AI 帮我写出一首完整的歌”，这个工具做不到。它的定位是给你一个还不错的和弦进行和基础编曲，你在此基础上改。

## 使用建议

推荐在电脑上使用（Chrome、Edge、Safari 都可以）。大屏幕配鼠标，编辑体验最好。

手机和平板暂不支持，因为布局会错乱，而且不易操作。

## 常见问题

**为什么本地双击 HTML 打不开？**

项目用了 ES modules，浏览器不允许 `file://` 协议加载。在线版没有这个限制，直接访问链接就行。本地测试请用 HTTP 服务，命令见下方。

**我的音乐存在哪里？**

全部存在你浏览器的 localStorage 里，不会上传到任何服务器。换浏览器或清缓存会丢失，建议用“导出工程文件”备份。

**支持哪些拍号？**

AI 作曲目前只支持 4/4。其他拍号下手动编辑正常，AI 生成会提示切回 4/4。

**生成的音乐能商用吗？**

可以。但 AI 只是起点，成品质量取决于你的修改。

## 技术栈

- 纯原生 ES modules，没有 npm、打包器、框架、CDN
- Web Audio API 实时合成、卷积混响、离线渲染导出 WAV
- 纯 JS 实现 SMF (MIDI) 读写、WAV 编码、LZSS 压缩分享链接、撤销/重做快照
- 26 个模块，分层是 `ui → io/ai/audio → core`，没有循环依赖

### 本地运行

在项目根目录执行：

    python -m http.server 8080

或者：

    npx serve -p 8080

然后浏览器打开 http://localhost:8080

### 项目结构

    index.html            只放 DOM 骨架，入口指向 ./js/main.js
    css/                  主题变量、布局、时间线样式
    js/main.js            入口：import + 错误监听 + hooks 注入 + boot()
    js/core/              util、theory、state、storage
    js/audio/             engine、synth、drum、master、render
    js/ai/                styles、rhythm、harmony、lead、compose
    js/io/                project、share、midi、wav
    js/ui/                timeline、sidebar、seek、piano、viz、toolbar、theme
    assets/favicon.svg    站点图标
