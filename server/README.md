# 分享短链后端（Cloudflare Worker + KV）

角色：把整份工程数据存进 KV，换回一个 8 位短 ID。于是分享卡片上的二维码只要放
`.../visualizer.html#p=<id>`（约 60 字节），**一张普通二维码就装得下** ——
不再需要 PDF417 之类的大码制，也不用多张二维码拼接。

## 部署（网页操作 + 两条命令）

```bash
# 1) 装 wrangler（一次性）
npm i -g wrangler

# 2) 建一个 KV 命名空间，把输出的 id 填进 wrangler.toml 的 id 字段
wrangler kv namespace create MP_KV

# 3) 部署
cd server
wrangler deploy
```

部署完会得到一个形如 `https://mp-share.<你的子域>.workers.dev` 的地址。

## 把地址告诉前端

前端按这个优先级找后端：

1. `localStorage.mpApiBase`（可视化页「设置 → 分享地址」下方可填，最方便）
2. `<meta name="mp-api-base" content="...">`（写死在 HTML 里，适合自建部署）
3. 都没有 → **短链功能自动禁用**并给出提示，其余功能不受影响

所以部署后建议把 `meta` 填上，或在前端填一次即可。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/p` | body = 分享载荷（`#z=…` / `#l=…` / `#s=…` 那串）→ `201 {id,url,bytes}` |
| `GET` | `/api/p/:id` | → `200 {data}`；不存在/过期 → `404 {error:'not_found'}` |
| `GET` | `/api/health` | → `200 {ok,kv}`（前端用它判断后端是否配好） |

## 设计取舍（改之前先读）

- **后端不解析工程数据**，只当不可变字符串存。将来前端换编码方式（`#z=`/`#c=`…）
  后端一行都不用改。
- 数据**不可变**：同一个 id 永不覆盖，所以不需要账号与鉴权；8 位随机 id 本身就是权限
  （base36 共约 2.8e12 种）。
- **TTL 180 天**：分享链接不该永久占存储；过期后前端明确报"链接已过期"。
- **按 IP 限流**（默认每小时 60 次创建），防止被当免费图床刷。
- **CORS 允许任意 Origin**：这是公开分享服务，不带 cookie / 凭据；收窄 Origin 会让
  fork 出去的自建前端用不了。
- 单份上限 512 KB（正常分享链接 1–20 KB）。

## 免费额度够不够

KV 免费档：读 10 万次/天、写 1000 次/天、存储 1 GB。
按每份 20 KB 算，1 GB 约存 5 万份；每天新建 1000 条短链对个人项目绰绰有余。
